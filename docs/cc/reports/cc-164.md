**D1 — `binomP99(n, p)`** (`packages/data/src/lib/cancellation-census.ts`).
- **Method:** a log-space walk.
  - `logP₀ = n·log1p(−p)`.
  - Each next term is `+ log(n−k) − log(k+1) + log p − log1p(−p)`.
  - It accumulates `exp(logP)` and returns the smallest k with CDF ≥ 0.99.
  - `n ≤ 0`, `p ≤ 0` or non-finite → 0; `p ≥ 1` → n.
