## Decisions

D1–D10 are as ratified. My calls inside them:

- **D9 is a second function**, `vote_roll_class(q, roll_call_id)`, so D3's
  `vote_question_class(text)` keeps its signature. Its regex is
  `^(?:[0-9]{4}-house|senate-[0-9]+-[0-9]+)-[0-9]+$`, character-equal to the TS
  `FEDERAL_ROLL_CALL_ID` (a test pins it).
- **D4's roll number is `DESC NULLS LAST`.** A numbered roll ranks above an
  unnumbered one on the same day. Default `DESC` would put NULLs first. The
  number is cast to `numeric`, so a long non-federal digit run cannot overflow.
- **The tier is ordered by the `strength` expression** (0.500 before 0.250),
  textually equal to the select-list item. It reuses that target entry, so the
  class is evaluated twice per row, not three times.
- **D7's UPDATE stamps `derived_at = NOW()`.**
  `ec_arm_source_fingerprint('entity_connection_stats_windows')` reads
  `count(*), max(derived_at)`, so an UPDATE-only merge that skipped the stamp
  would let the stats arm skip a cycle whose edges moved. The cost: those
  updates are never HOT (63,907 on the clone, 0 HOT).
- **The helpers are `REVOKE`d from PUBLIC, anon and authenticated**, with
  `GRANT EXECUTE` to service_role, as for the arms.
- **D7's retype is a DELETE then INSERT, never an UPDATE of a key column.**
  The counts rely on one votes edge per pair, which read 5 found holds (0
  pairs with two).
