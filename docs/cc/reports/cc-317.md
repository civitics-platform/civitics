## Decisions I changed, with the evidence

- **D1, grants.** `vote_roll_class()` and `vote_question_class()` are service_role-only (FIX-1409). On the clone, a security-invoker caller running as `anon` reads `ERROR: permission denied for function vote_roll_class`. Both are IMMUTABLE functions of text and read no table, so the same file grants them EXECUTE to `anon` and `authenticated`. Their bodies are untouched. All three names joined the FIX-1113 allow-list.
- **D1, order.** I used FIX-1409's roll number inside a day, `substring(roll_call_id FROM '([0-9]+)$')::numeric DESC`, ahead of `roll_call_id DESC`. `voted_at` is a date, and text order puts `house-99` above `house-100`.
- **D6, the path follows the measure's kind.** Simple resolutions (HRES/SRES; clone 292 + 12 of 888 federal resolutions) end at **Agreed to**. Concurrent ones (HCONRES/SCONRES; 30 + 7) end at **Passed both**. Bills and joint resolutions take the full path to Law. Other mappings:
  - `passed_committee` shows as In committee.
  - `vetoed` shows Passed both as reached, then the end state.
  - `failed`, `withdrawn` and `tabled` mark only Introduced, because they say nothing about how far the measure got.
- **D11.** `summary_plain` now always renders under "Summary". Before, it rendered under "What This Means" whenever no AI row existed, which credited the source text to the wrong author.
- **D2.** "· N other" is added only when paired or abstain casts exist, so the parts always sum to R.
- **D4.** On the headline roll, each cast is a collapsed `<details>` showing "N recorded (D x · R y)" from `by_party`, so 430 names are not open by default.
- **D8.** `initiative` → "Citizen Initiative", the app's existing name. `ProposalCard` has no bill number, so federal nominations read "Appointment" on cards.
- **D10.** Tags are filtered to `tag_category = 'topic'` and `visibility IN ('primary','secondary')`, and render with `variant="full"`.
- **Added without being asked:**
  - Four statuses had no badge label: `vetoed`, `veto_overridden`, `tabled` and `final_rule`. The Details card's new Status row would have printed those raw, so I added labels.
  - `formatDate` now formats in UTC. The values are dates at midnight UTC and Vercel renders in UTC, so a local dev server printed the day before.
