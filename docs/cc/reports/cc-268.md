## What contradicted the design

- **The premise that GovTrack v2 is a reachable programmatic source.** The
  prompt's own caveat was that the Cowork sandbox could not reach govtrack.us,
  and it put that down to an allowlist. The real cause is upstream of any
  allowlist: GovTrack challenges programmatic clients at its Cloudflare
  edge, and the dev box hits it too. The cosponsors skeleton's "intermittent
  historically" note may be an earlier sighting of the same policy.
- **Two of the named sources are now blocked by a bot-management layer:**
  senate.gov (Akamai, since 10-23) and GovTrack (Cloudflare, today). A third,
  congress.gov, has no Senate votes. Any "second source" that is a
  public website is exposed to the same class of policy. A design that assumes
  a public HTML/JSON host is free to read needs a reachability read before it
  is ratified, the way this prompt's read 1 gated it.
- **Not measured: the GHA egress.** The nightly runs from GitHub-hosted
  (Azure) IPs. Datacenter ranges usually score *worse* under Cloudflare bot
  management, so a dev-box challenge is unlikely to be a GHA pass, but this
  run did not measure it.
