## 4. What contradicted the design

- **A NULL override cannot de-tag an ai row.** The exact path in `rules.ts`:
  - The override read (`tagFinancialEntities`, two LEFT JOINs, one per arm) feeds `applyIndustryOverrides()`. That drops every *computed* keyword or NAICS industry row for an overridden entity, then emits one curated row, or none when `industry IS NULL`.
  - Inside `withTagRebuild`, `clear_financial_entity_rule_tags(['industry'])` deletes only `generated_by='rule'` and `clearCuratedIndustryTags` only `'curated'`.
  - An ai row survives all three steps, and `primary_industry_tag()` ranks curated > rule-before-ai > confidence without reading the override table.
  - So the prompt's "NO DELETE (FIX-1259 keeps the ai rows — the override's curated row wins)" holds only for a non-NULL override. For the three NULL verdicts, nothing is curated to win.
  - Craig authorised the scoped delete. The ai classifier skips overridden committees (FIX-917), so the rows will not come back.
- **The IE four are not keyword hits.** The prompt said "the IE top-50's four 'wrong → lobby' … item 2 fixes them". The audit's own §7 rows say "no tag" for all four (LCV Victory Fund $150.4M, UDP $107.7M, EDF Action Votes $37.6M, Everytown Victory Fund $37.3M IE). D2 cannot add lobby to them.
