## Decisions — what I changed or added

1. **D2's directory half rode Item 1, not Item 2.** D1's `not_published` is "the
   listing does not name the file", and the listing is the `daily-index`
   quarter directory's. Checking a `full-index` URL against it would be
   incoherent. Item 2 carries D2's form names, D3 and D4.
2. **A refused index does not turn the fec-phase red.** The prompt said
   `failed` through `failSync` and was silent on the nightly. FIX-757's rule is
   that a failed pipeline exits the phase 1, which flips `nightly_cron` to
   `partial` and freezes the freshness clocks. I took the opm-fte precedent
   (`index.ts`'s "non-fatal … don't add to errors array"): the `edgar_daily` row
   says `failed`, `results.pipelines.edgar_daily` says `failed`, and
   `results.errors` is untouched. The reason is that an outside archive's
   refusal of a dry collector should not redden the phase. **Craig's call to
   flip it** when the writes go on. The standalone CLI exits 1 on it (FIX-727).
3. **`skipSync` takes optional metadata**, merged under `skip_reason` the way
   `failSync`'s FIX-1268 parameter is. It is additive, and no other caller
   changes.
4. **D4 extra keys:** `rows_13dg_by_form`, which counts every 13D/13G-looking
   name so a third renaming shows, and `fetch_errors`. Write mode keeps the
   same keys with `dry_run: false`.
5. **D3's "first days" = 7.** Inside the window, a refused new-quarter listing
   is tolerated while the previous quarter's reads. Outside it, a refused
   listing is `refused`.
6. **D7 widened in two places.** A downloads page that lists no archive is a
   download failure: `zips_failed` gets `{zip: "(downloads page, YEAR)"}`.
   `zips_via_unzip` names the archives read by the fallback. Each key appears
   only when non-empty. One consequence: a run whose archives all stream but
   miss an id stays `complete` (per D7's letter) and now names the id in
   `object_ids_unresolved`.
7. **D6's fallback failure** rethrows `"<original>; unzip fallback failed —
   <unzip's error>"`. A *missing binary* rethrows the original unchanged, as
   the prompt asked.
