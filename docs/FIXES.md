# FIXES — Civitics Platform

Actionable improvement backlog. Every item has a priority, complexity, and enough context to hand to Qwen or Claude Code directly.

**Priority key:**
- 🔴 Critical — Bug that breaks or blocks real functionality
- 🟠 High — Meaningful product/UX gap, address soon
- 🟡 Medium — Worthwhile improvement, schedule when practical
- 🟢 Quick Win — Small effort, high visible impact (batch these)
- ⬜ Future — Phase 2+ or requires significant design/pipeline work

**Complexity key:** S = <2h · M = 2–8h · L = 1–3 days · XL = multi-day + planning

**Workflow:** Every bullet has a stable ID (`<!--id:FIX-NNN-->`). Don't remove or renumber IDs — they're the handle commits reference via `Fixes: FIX-NNN` trailers.

**This file is hand-edited only (FIX-1016).** It holds prose and the ID marker. It carries **no status** — no `[ ]`, no `[x]`. Completion lives in `docs/done.log`, which is append-only, and is *derived* from it:

> **OPEN** if the ID has no row in `done.log`, or if its **last** row has `reopen` in the sha column. **CLOSED** otherwise.

Ask the question with **`pnpm fixes:status FIX-NNN`** (or `pnpm fixes:status` for the whole open backlog, `--json` for a machine). `pnpm session:check` prints the same summary at the top of every session. See [CLAUDE.md](../CLAUDE.md#fixes-workflow) for the full contract.

**Bullet shape:** `- {emoji} {S|M|L|XL} — **title** — body <!--id:FIX-NNN-->`. Use `pnpm fix:add` rather than hand-formatting; it allocates the next free ID atomically and writes this shape.

**Section rules:**
- Active sections hold open items. `pnpm fixes:clean` moves closed ones to `## COMPLETED`; `pnpm fixes:archive` moves those out to `docs/archive/fixes-archive.md`. Both are run deliberately by a human, never as a side effect of a sync.
- `## COMPLETED` is a holding pen between those two commands — normally empty.
- Deferred / blocked items stay in active sections, never in COMPLETED. If something was closed prematurely, `pnpm fix:reopen FIX-NNN --note "why"` (or a `Reopens: FIX-NNN` commit trailer) appends a `reopen` row and the derivation does the rest. Nothing in this file changes.
- Bullets in `docs/archive/fixes-archive.md` still show `[x]`. That is history, written before the strip, and is left exactly as it was.
